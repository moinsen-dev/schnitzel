## Usage Example

```python
from pathlib import Path
from schnitzel.schema.models import SchnitzelSchema, Model, FieldDefinition
from schnitzel.generators.python.models import PythonModelGenerator

# Define schema
schema = SchnitzelSchema(
    models={
        "User": Model(
            name="User",
            fields={
                "id": FieldDefinition(type="uuid"),
                "email": FieldDefinition(type="string", max_length=255),
            }
        )
    }
)

# Generate to file
generator = PythonModelGenerator()
output_path = generator.generate_to_file(
    schema,
    "backend/app/generated",
    schema_source="users.schnitzel.yaml"
)

print(f"Models written to: {output_path}")
# Output: Models written to: backend/app/generated/models.py
```
