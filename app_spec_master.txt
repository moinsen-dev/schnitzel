  <overview>
    Schnitzel is a schema-driven full-stack code generator that eliminates friction between
    Flutter frontends and Python (FastAPI) backends. It provides a unified YAML schema language
    that generates type-safe code for both platforms, ensuring consistency across the entire stack.

    The framework consists of 84+ components including a CLI tool with 14 commands, 18 code
    generators, runtime libraries for both Python and Dart, and AI-first tooling.
  </overview>
