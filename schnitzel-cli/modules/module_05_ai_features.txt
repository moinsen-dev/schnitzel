    <claude_md_generation>
      - Generate CLAUDE.md with project context
      - Include: tech stack, architecture, key patterns
      - Include: model definitions and relationships
      - Include: API endpoints summary
      - Include: coding conventions and style guide
      - Update on each `schnitzel generate`
    </claude_md_generation>

      - Generate MCP server for project tools
      - Tools: add_model, add_field, add_endpoint
      - Tools: validate_schema, generate_code
      - Resources: schema.yaml, models list, endpoints list
      - Prompts: feature request template, bug fix template

```markdown
# My Blog - AI Context

## Overview
A blog application built with Schnitzel Framework.
- **Frontend**: Flutter with BLoC pattern
- **Backend**: FastAPI with SQLAlchemy
- **Database**: PostgreSQL

## Architecture

### Models
| Model | Fields | Relations |
|-------|--------|-----------|
| User | id, email, name, created_at | has_many: posts, comments |
| Post | id, title, content, author_id | belongs_to: user, has_many: comments |
| Comment | id, content, post_id, user_id | belongs_to: post, user |

### API Endpoints
- `GET /api/users` - List users (paginated)
- `POST /api/users` - Create user
- `GET /api/users/:id` - Get user by ID
...

## Key Files
- `schema.schnitzel.yaml` - Data model definitions
- `apps/my_blog/lib/` - Flutter app source
- `backend/app/` - FastAPI backend source

## Commands
- `schnitzel generate` - Regenerate code from schema
- `schnitzel serve` - Start backend server
- `schnitzel test` - Run all tests

## Conventions
- Models use PascalCase, fields use snake_case
- BLoC pattern for state management
- Repository pattern for data access
```
