  <overview>
    Advanced schema features for complex business logic:
    - State machines for status fields
    - Computed fields (virtual and stored)
    - Triggers and hooks (before_create, after_update, etc.)
  </overview>

  <core_features>
    <state_machines>
      - Define allowed transitions for status fields
      - Guards for transition validation
      - Events triggered on transitions
      - Example:
        ```yaml
        status:
          type: state_machine
          initial: draft
          states: [draft, review, published, archived]
          transitions:
            - from: draft, to: review, guard: has_content
            - from: review, to: published, guard: is_approved
            - from: [draft, review, published], to: archived
        ```
    </state_machines>

    <computed_fields>
      - Virtual fields calculated on read
      - Stored fields calculated and persisted
      - Expression-based calculations
      - Example:
        ```yaml
        full_name:
          type: computed
          expression: "first_name + ' ' + last_name"
          stored: false
        total_price:
          type: computed
          expression: "quantity * unit_price"
          stored: true
        ```
    </computed_fields>

    <triggers>
      - before_create, after_create
      - before_update, after_update
      - before_delete, after_delete
      - Custom trigger actions
      - Example:
        ```yaml
        triggers:
          before_create:
            - set: created_at, value: now()
            - validate: email_unique
          after_create:
            - emit: user.created
            - call: send_welcome_email
        ```
    </triggers>
  </core_features>

```python
from transitions import Machine

class PostStateMachine:
    states = ['draft', 'review', 'published', 'archived']

    transitions = [
        {'trigger': 'submit', 'source': 'draft', 'dest': 'review',
         'conditions': 'has_content'},
        {'trigger': 'approve', 'source': 'review', 'dest': 'published',
         'conditions': 'is_approved'},
        {'trigger': 'archive', 'source': ['draft', 'review', 'published'],
         'dest': 'archived'},
    ]

    def __init__(self, post):
        self.post = post
        self.machine = Machine(
            model=self,
            states=self.states,
            transitions=self.transitions,
            initial=post.status
        )

    def has_content(self):
        return bool(self.post.content)

    def is_approved(self):
        return self.post.approved_by is not None
```

```python
class User(Base):
    first_name = Column(String)
    last_name = Column(String)

    @hybrid_property
    def full_name(self) -> str:
        return f"{self.first_name} {self.last_name}"

    @full_name.expression
    def full_name(cls):
        return cls.first_name + ' ' + cls.last_name
```

```python
@router.post("/users", response_model=UserRead)
async def create_user(user: UserCreate, db: Session = Depends(get_db)):
    # before_create triggers
    user_dict = user.model_dump()
    user_dict['created_at'] = datetime.utcnow()

    # validate email_unique
    if db.query(User).filter(User.email == user.email).first():
        raise HTTPException(400, "Email already exists")

    db_user = User(**user_dict)
    db.add(db_user)
    db.commit()

    # after_create triggers
    await emit_event('user.created', db_user.id)
    await send_welcome_email(db_user.email)

    return db_user
```
